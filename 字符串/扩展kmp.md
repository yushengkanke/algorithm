# 解决问题  
以线性复杂度求出一个字符串s和它的任意后缀s[i......n]的最长公共前缀长度。  
# 与kmp区别  
kmp是到s[i]结束匹配，而exkmp是从s[i]开始匹配  
# 具体分析  
对于i大于1的位置i，用z[i]表示字符串s和后缀s[i.....n]的最长公共前缀的长度   
定义z[1]=0，然后从2到n枚举i，依次计算z[i]的值   
假设正在计算z[i]的值，z[i]之前的值都已经算好了  
对于任意j(j小于i)，有s[j...j+z[j]-1]=s[1...z[j]]  
为了计算z[i]，在枚举i的过程中，我们需要维护一个R最大的区间[L，R]其中  
L=j......R=j+z[j]-1   
初始L=1，R=0。  
设k为从k到1或R-L+1的距离一一对应等于从i到L或R的距离的点   
若i小于等于R且z[k]小于R-i+1，则说明从k开始匹配后缀，后缀的长度到不了R，此时z[i]=z[k]    
如果i小于等于R且z[k]大于等于R-i+1，即从k开始可以匹配到R-L+1，也就是从i开始可以匹配到R，此时从R+1开始暴力匹配即可，令z[i]=R-i+1,开始暴力。求出z[i]后更新L和R     
# 板子   
```c++
void exkmp()
{
    int L=0,R=1;
    z[1]=0;
    for(int i=2;i<=n;i++)
    {
        if(i>r){
            z[i]=0;
        }
        else{
            int k =i-L+1;
            z[i]=min(z[k],R-i+1);
        }
        while(i+z[i]<=n&&s[z[i]+1]==s[i+z[i]])
        {
            ++z[i];
        }
        if(i+z[i]-1>R)
        {
            L=i;
            R=i+z[i]-1;
        }
    }
}
```
