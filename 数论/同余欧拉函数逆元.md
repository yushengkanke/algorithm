# 逆元  
![](/images/数论/9.png)  
一个数a的倒数就是它自己的逆元，当然逆元有很多  
在取模运算中，除以一个数可以等效成乘这个数的逆元   
例如(14/7)%10就等于(14%10)*(3%10)而不是(14%10)/(7%10)，7*3=21;21%10=1%10;3是7的逆元  
# 求逆元  
对于一个数a来说，如果模数为m(m为质数)，则a的逆元为a的m-2次幂（快速幂求解）  
阶乘求逆元：(p为模数(质数)，阶乘为n!)  
公式(O(nlog(n))):inv[i]=(p-p/i)*inv[p%i]%p;(inv[i]代表数字i本身的逆元，相当于直接把阶乘里每个数的逆元都求出来了)  
公式：inv_fact[i]=inv_fact[i-1]*inv[i]%p；(类似前缀和)  
对取模运算来说，如果%p的p为常量，编译器会使用神秘小代码把取模运算变得快一点，所以对于p固定的题目，推荐
```c++ 
const int MOD =998244353;
```

```c++
// 计算逆元
int modInverse(int a, int m) {
    int x, y;
    exgcd(a, m, x, y);
    x %= m;
    if (x < 0) x += m;
    return x;
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

// ==================== 组合数预处理板子（方法一：费马 + 逆推） ====================
// 适用条件：MOD 为大质数（如 1e9+7, 998244353），且 最大查询范围 n < MOD
// 时间复杂度：O(n + log MOD) 预处理，O(1) 查询
// 空间复杂度：O(n)
// ========================================================================

typedef long long ll;

const int MOD = 1e9 + 7;   // 常用模数，若为 998244353 需确保为质数
const int MAXN = 1e6 + 5;  // 根据题目最大 n 调整，需保证 MAXN < MOD

ll fact[MAXN];      // fact[i] = i! % MOD
ll inv_fact[MAXN];  // inv_fact[i] = (i!)^(-1) % MOD

// 快速幂：计算 a^b % MOD
ll qpow(ll a, ll b) {
    ll res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

// 预处理阶乘及其逆元 (传入最大需要的 n)
void init(int n) {
    // 1. 顺推求阶乘
    fact[0] = 1;
    for (int i = 1; i <= n; i++) {
        fact[i] = fact[i - 1] * i % MOD;
    }

    // 2. 费马小定理求 n! 的逆元（仅一次快速幂）
    inv_fact[n] = qpow(fact[n], MOD - 2);

    // 3. 核心：逆推求所有阶乘逆元
    // 公式: inv_fact[i-1] = inv_fact[i] * i % MOD
    for (int i = n; i >= 1; i--) {
        inv_fact[i - 1] = inv_fact[i] * i % MOD;
    }
}

// 查询组合数 C(n, k) % MOD
// 若题目 n 很大（>= MOD），此函数失效，需另写 Lucas 定理
ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD;
}

// ==================== 使用示例 (主函数) ====================
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 假设题目最大需要求到 100000
    int max_n = 100000; 
    init(max_n);

    // 示例：查询 C(5, 2)
    cout << "C(5, 2) = " << C(5, 2) << endl; // 输出 10

    // 竞赛中多次查询
    int T, n, k;
    cin >> T;
    while (T--) {
        cin >> n >> k;
        cout << C(n, k) << '\n';
    }

    return 0;
}
```
