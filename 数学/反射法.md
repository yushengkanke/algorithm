# 展开法  
主要思想是不管光线的反射，将它当成直线传播，然后边界无限延展，类似MC的区块。对于该延展后的平面上的每一个点，可以通过映射公式来算出在原边界内的对应点。  
公式：  
![](/images/数学/反射法2.png)  
代码：  
```c++
int fold(long long pos, int L) {
    long long p = pos % (2 * L);
    return (p > L) ? (2 * L - p) : p;
}
```
该扩展后的表具有周期性，周期为2倍的长或者宽。因此对于任意一个点的x或y坐标，其在扩展后的表上的位置t=x+q\*2\*m或者t=(2\*m-x)+q*2\*m(m为对应坐标表的边长，q为任意值)。对于四个角来说，t=0+qm 或t=m+qm    
由此可见，可以化简为t=x(mod m)的形式，然后可用中国剩余定理解出来方程组的t。
