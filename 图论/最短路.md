# bellman-ford  
用于解决单源最短路问题    
特点：可以处理负权边，可以检测从源点可达的负权环，时间复杂度为O(VE)比dijkstra慢，但适用性广    
## 松弛操作  
该算法的核心思想就是松弛操作，即对于边(u,v)，用dist(u)和l(u,v)来尝试更新dist(v)。   
```c++
dist(v)=min(dist(v),dist(u)+l(u,v))
```
感觉本质就是把所有可能经过v的路线全列举出来然后找最小的值。来回循环n遍类似于两层for循环，来找到最正确的答案。每一次循环都会使真正的最短路往前进一层。  
当循环次数达到了n轮以上的时候，可以确认出现了负环（可以判断负环这不阴？）   
## 板子  
```c++
typedef struct Edge{
    int x,y,v;

} edge[M+1];
int n,m,dist[N+1],pre[N+1];
int shortestpath(int s,int t)
{
    memset(dist,127,sizeof(dist));
    dist[s]=0;
    for(;;)
    {
        bool ok =false;
        for(int i=0;i<=m;i++)
        {
            int x =edge[i].x;
            int y = edge[i].y;
            int v=edge[i].v;
            if(dist[x]<1<<30)
            {
                if(dist[x]+v<dist[y])
                {
                    dist[y]=dist[x]+v;
                    pre[y]=x;
                    ok=true;
                }
            }
            if(!ok){
                break;
            }
        }
    }
    return dist[t];
}
```
