# 最小生成树  
一张有权无向连通图中边权和最小的生成树叫做最小生成树。如果原图不连通，则没有最小生成树。
# prim算法  
做法类似于dijkstra，我们仍然维护一个顶点集合c，每次通过一条边连接一个不在c中的点，直到最后形成一个树形结构  
定义dist(u)为连接c中任意点和u的边权的最小值，我们把dist(u)称为u到c中的距离。
将任意点x加入C，此时C中只有一个点x，对于其他点y，如果x,y之间有边，则dist(y)等于这些边边权的最小值，否则dist(y)为无限大    
在每一轮中，将dist最小的还不在c中的顶点z加入c，同时将连接c与z的边权最小的边加入最小生成树的边集，用z连接其他的边尝试更新其他点的dist
