# 最小生成树  
一张有权无向连通图中边权和最小的生成树叫做最小生成树。如果原图不连通，则没有最小生成树。
# prim算法  
做法类似于dijkstra，我们仍然维护一个顶点集合c，每次通过一条边连接一个不在c中的点，直到最后形成一个树形结构  
定义dist(u)为连接c中任意点和u的边权的最小值，我们把dist(u)称为u到c中的距离。
将任意点x加入C，此时C中只有一个点x，对于其他点y，如果x,y之间有边，则dist(y)等于这些边边权的最小值，否则dist(y)为无限大    
在每一轮中，将dist最小的还不在c中的顶点z加入c，同时将连接c与z的边权最小的边加入最小生成树的边集，用z连接其他的边尝试更新其他点的dist   
适合稠密图，复杂度和顶点相关。边权可以为负   
Prim 算法就是从一个点开始，每次用最小边“长”出生成树，直到覆盖所有顶点    
时间复杂度0(n^2+m)（朴素做法）
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = 1e18;

/*
 * Prim 求最小生成树（MST）
 * 顶点编号：0 ~ n-1
 * adj[u] 存 {v, w}：u 到 v 的边权为 w；无向图需双向加边
 * 返回 MST 总权值；图不连通返回 -1
 * 复杂度：O(E log V)，空间 O(V+E)
 * 边权用 long long，支持负权；start 为起点，默认 0
 * 需要 C++17
 */
ll prim(int n, const vector<vector<pair<int, ll>>>& adj, int start = 0) {
    vector<ll> dist(n, INF);//存储顶点 i 到当前生成树集合的最小边权
    vector<char> vis(n, 0);//记录顶点 i 是否已经加入生成树
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;//维护还没有被连进树的点的边权的最小的那个

    dist[start] = 0;
    pq.push({0, start});

    ll sum = 0;
    int cnt = 0;

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (vis[u]) continue;
        vis[u] = 1;
        sum += d;
        cnt++;

        for (auto [v, w] : adj[u]) {
            if (!vis[v] && w < dist[v]) {
                dist[v] = w;
                pq.push({w, v});
            }
        }
    }

    return cnt == n ? sum : -1;//返回边权和，如果没有最小生成树返回-1；
}

```
# kruskal 算法
通过维护一个并查集，通过边权从小到大依次连接，直到集合中包含所有的点，这是一个贪心的思想。
## 过程 
初始化并查集，一开始所有点的代表元都是它自己。   
将所有边按照边权从小到大排序   
按边权从小到大枚举所有边，如果这个边的两个顶点位于同一个集合，则什么也不做，否则，将两个点的集合合并，且将边存在最小生成树的边集里。   
直到最后只剩下一个集合，然后结束。  
## 代码 
```c++
//O(mlogn)
struct Node{
    int x,y,v;
    bool operator < (const Node &A) const
    {
        return v < A.v;
    }
} a[M+1];
int n,m,fa[N+1];//并查集
int findset(int i)
{
    if(i==fa[i])
    {
        return i;
    }
    return fa[i]=findset(fa[i]);
} //并查集查找父
int kruskal (){
    for(int i=1;i<=n;i++)
    {
        fa[i]=i;

    }
    sort(a+1,a+m+1);
    int ans = 0,cnt =n;
    for(int i=1;i<=m;i++)
    {
        int x = findset(a[i].x),y = findset(a[i].y);
        if(x!=y)
        {
            fa[x]=y;
            ans+=a[i].v;
            --cnt;
        }
        if(cnt==1)
        {
            break;
        }
    }
    if(cnt !=1)
    {
        return -1; //不存在最小生成树
    }
    else {
        return ans;
    }
}
```
