# 单调栈独有性质  
栈是 LIFO（后进先出），所以它重点关注 “左边/右边第一个” 的邻近关系。  
处理范围：通常用于处理一维数组中，寻找每个元素左边/右边第一个比它大（或小）的元素（如接雨水、柱状图最大矩形）。  
弹栈时的“决定性”瞬间：当新元素 x 触发弹栈时（例如维护递减栈，x > 栈顶），当前被弹出的栈顶元素的“右边第一个更大值”就是 x；而它被弹出后，新的栈顶就是它“左边第一个更大值”。这个弹出时刻即答案的确定时刻。  
通常用于查找数组中的数的左边或右边离它最近的比它大或小的数。  
# 单调队列独有性质   
队列（通常使用双端队列 deque）是 FIFO（先进先出），所以它多了一个关键的 “窗口滑动” 维度。  
处理范围：专门用于处理滑动窗口类问题（如滑动窗口最大值、最小值）。  
“过期”淘汰（双约束淘汰）：单调队列的淘汰规则有两个维度：  
值维度：新元素从队尾弹出比它小的旧元素（维持单调性）。  
下标维度：在每次窗口滑动时，检查队首元素的下标是否已经滑出当前窗口，如果是，必须从队首弹出。    
通常可以用于确定区间的最大或最小值（也可以是具有类似性质的其他特点的数（感觉））  
建议存储下标，便于检查数字是否超出区间。   
下面是查询区间最大值代码，其中返回的结果数组result中第i个数表示区间右端点在i的时候的区间内最值             
```c++
#include <iostream>
#include <vector>
#include <deque>

using namespace std;

vector<int> slidingWindowMax(const vector<int>& nums, int k) {
    vector<int> result;
    deque<int> dq; // 存储元素下标，保持下标对应的值从大到小

    for (int i = 0; i < nums.size(); ++i) {
        // 1. 移除队首不在当前窗口内的下标（过期元素）
        if (!dq.empty() && dq.front() < i - k + 1) {
            dq.pop_front();
        }

        // 2. 维护单调递减：从队尾弹出比当前元素小的所有下标
        while (!dq.empty() && nums[dq.back()] <= nums[i]) {
            dq.pop_back();
        }

        // 3. 将当前元素下标入队
        dq.push_back(i);

        // 4. 当窗口完整时，记录结果（队首即为最大值）
        if (i >= k - 1) {
            result.push_back(nums[dq.front()]);
        }
    }
    return result;
}

int main() {
    vector<int> nums = {1, 3, -1, -3, 5, 3, 6, 7};
    int k = 3;
    vector<int> maxs = slidingWindowMax(nums, k);
    for (int x : maxs) cout << x << " "; // 输出: 3 3 5 5 6 7
    return 0;
}
```
