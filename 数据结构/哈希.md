# 概念  
其实就是数学上的映射关系，你通过输入一个数，然后可以通过一个转换公式将它变成另外一个数，然后用这个数当下标去存储值。因此哈希函数可能会有冲突。
## 解决方法  
可以使用vector来解决冲突。我们开一个二维vector，当需要存储新值的时候就push_back进去，如果有冲突，就是说其对应的vector有多个值。   
我们不难看出，哈希表时间复杂度是O(1)的，但是又因为存在冲突，所以它会退化成o(n)，因此，我们要保证减少冲突。   
当映射关系为x%p时，我们应该让p为质数(原因是数论内容)，这样才会使分布平均。  
哈希表的容量为哈希表的长度，即上文的p。   
负载因子为把哈希表元素的总数除哈希表容量。   
当负载因子达到0.7到0.8的时候，冲突会变得频繁，这时候要考虑增大哈希表的容量。  
## 字符串哈希  
可以把字符串看成一个正常的带进制的数，进制一般要大于字符的种类，然后取模。可以通过这个来简化算法的步骤，但是，这种方法不保证完全正确，只能保证绝大部分正确。    
就看成：H(s)=s0*B^n-1+s1*B^n-2......+sn-1*B^0(mod M)  
我们定义前缀哈希：h[0]=0    h[i]=(h[i-1]*B+s[i-1]) mod M;    
h[i]表示前i个字符的哈希值   
预处理幂：p[0]=1;   p[i]=p[i-1]*B mod M;    
则字串s[l...r]为：hash(l,r) = h[r+1]-h[l]*p[r-l+1](mod M); 若结果为负，则加上MOD。    
这样求任意字串哈希都是o(1).   
常见应用：  
字符串匹配  
计算模式串哈希，再枚举文本中所有等长子串哈希，O(n+m)。  

判断回文  
对原串和反串分别哈希，判断正反子串哈希是否相等。  

最长公共前缀 LCP  
二分长度，用哈希比较两个后缀的相同长度前缀。   

最长重复子串  
二分长度，把所有该长度子串哈希丢进哈希表判重。  

字符串去重   
用子串哈希代表子串，放入 set 或 unordered_set。  

比较两个子串字典序   
二分 LCP，再比较第一个不同字符。   
```c++
//字符串双哈希 
struct DoubleHash {
    static const long long MOD1 = 1000000007;
    static const long long MOD2 = 1000000009;
    static const long long BASE = 131;

    int n;
    vector<long long> h1, h2, p1, p2;

    DoubleHash(const string& s) {
        init(s);
    }

    void init(const string& s) {
        n = s.size();
        h1.assign(n + 1, 0);
        h2.assign(n + 1, 0);
        p1.assign(n + 1, 1);
        p2.assign(n + 1, 1);

        for (int i = 0; i < n; i++) {
            long long v = (unsigned char)s[i]; // 也可用 s[i]-'a'+1
            h1[i + 1] = (h1[i] * BASE + v) % MOD1;
            h2[i + 1] = (h2[i] * BASE + v) % MOD2;
            p1[i + 1] = (p1[i] * BASE) % MOD1;
            p2[i + 1] = (p2[i] * BASE) % MOD2;
        }
    }

    // 返回 s[l..r] 的哈希，0-indexed，包含 l 和 r
    pair<long long, long long> get(int l, int r) {
        long long a = (h1[r + 1] - h1[l] * p1[r - l + 1]) % MOD1;
        long long b = (h2[r + 1] - h2[l] * p2[r - l + 1]) % MOD2;
        if (a < 0) a += MOD1;
        if (b < 0) b += MOD2;
        return {a, b};
    }
};
```
